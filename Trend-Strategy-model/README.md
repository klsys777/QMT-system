🎯 入场规则
以下为做多逻辑说明，做空逻辑相反（完全相反）
1. 入场条件（做多）
  •	出现连续的三根阳线（收盘价 > 开盘价）（以下条件为并列关系）
      o	每根阳线的收盘价均位于该K线实体部分的 上三分之一区间
      o	这三根阳线的 最高价 依次升高
  •	高低点结构条件（以下条件满足一条即可入场）（若使用指标，则为左边5~6根，右边2~3根）
      o	最近一个已确认的波段转折点是 更高的高点（HH）
      o	最近一个高低点判断为HL，前一个为HH。若前一个还是HL可以再向前追溯，一致追溯到HH为止。即HH和HL之间可以有无数个HL，但不能有LL/LH
  •	RSI指标判断（当前RSI值 > 70 ，开始RSI判断，否则这一项默认通过）
      o	情况一（前HH在30根K线内）：
            a	找到 前一个HH的最高点 及其 前后三根K线
            b	取这 7根K线中最高的前区域RSI峰值。
            c	第三根阳线收盘后，价格最高点 超过 前HH的最高点，且当前RSI 大于 前区域RSI峰值，可以入场
      o	情况二（前HH在30根K线前）：
            a	在 最近30根K线内，找到 RSI最高的那根K线。
            b	取该K线 前后三根K线（共7根），找出前区域价格峰值。
            c	入场条件： 第三根阳线收盘后，价格最高点 超过 前区域价格峰值，且当前RSI 大于 前一个RSI最高值，可以入场

2. 入场挂单规则
•	当触发入场信号，在最高点上方一个最小波动挂突破单
•	若 3 根 K 线内未被触发，则取消突破单

🏆 止盈 / 止损
🏆 止盈逻辑
•	1：1盈亏比，等同一倍初始止损

⚠️ 止损逻辑
1. 初始止损设在入场那三根阳线的最低价下面。
2. 移动止损
入场后，当创造出新的HH→新的HL→价格再突破HH后。移动止损移到新的HL下方。

🚪 主动出场规则
•	如果止损止盈一直没有被触发，则固定 K 线数离场（可默认20~30K离场）
